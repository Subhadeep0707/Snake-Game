# Snake Game 🐍

A classic Snake Game built using Java Swing, featuring keyboard controls, food collection, score tracking, and collision detection.

## Features
- Keyboard-controlled snake movement
- Food collection and snake growth
- Score and snake length tracking
- Collision detection with the snake's body
- Game Over screen and restart functionality
- Custom graphics for the snake, food, and title

## Tech Stack
- **Language:** Java
- **GUI:** Java Swing, AWT
- **Event Handling:** KeyListener, ActionListener
- **Game Loop:** Swing Timer

## How to Run
1. Clone this repository.
2. Open the project in your Java IDE.
3. Ensure the image assets are available in the `SNg` package.
4. Run `SMain.java` to start the game.

## Controls
- **Arrow Keys:** Move the snake
- **Spacebar:** Restart the game
